# VideoStream

## ¿Qué es?

VideoStream es una simulación sencilla de una página de videos. Está inspirada en la interfaz de plataformas como YouTube y fue hecha para practicar HTML, CSS y JavaScript.

La página incluye una vista adaptable para computador, tablet y celular.

## ¿Cómo está hecha?

- **HTML:** contiene la estructura de la página, el video, los botones, la cola y los videos recomendados.
- **CSS:** se encarga del diseño, los tamaños, los espacios y la adaptación a distintos tamaños de pantalla.
- **JavaScript:** agrega las interacciones de la simulación.
- **Imágenes y video:** están guardados dentro de la carpeta `static`.

## Interacciones

La simulación permite:

1. Aumentar el contador de "Me gusta".
2. Aumentar el contador de "No me gusta".
3. Suscribirse al canal y cambiar el botón a "Suscrito".
4. Añadir videos a la cola mediante una alerta.
5. Eliminar videos de la cola.
6. Limpiar toda la cola.
7. Reproducir una vista previa al pasar el mouse sobre una miniatura.
8. Reproducir el video principal usando los controles del navegador.
